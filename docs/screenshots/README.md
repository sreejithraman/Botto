# Native app captures

The README uses these running-app captures:

- `welcome.png`: Botto welcome, brand trio, and shared tagline.
- `inbox.png`: the labeled demo workspace with sample bots and activity.
- `chat.png`: a sample conversation with an approval request.

Demo bots, conversations, and decisions perform no real work. Use only sample
data for public captures. Keep personal notifications, credentials, hostnames,
account details, and private chats out of screenshots. Do not substitute design
mockups for running-app captures.

Capture the release version with settled content and enabled controls. Check
the saved PNGs at full size, including text, system chrome, and image metadata.
Refresh screenshots when the interface changes. Record the app revision and
target in the [verification record](../verification.md).
