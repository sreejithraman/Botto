# Choose a face and observe motion (`avatars`)

Run in a disposable workspace or explicitly choose Demo for in-memory
observations. See [avatars](../../../avatars.md). These checks are draft.

- `avatars.edit` — Change a shape and color, cancel, and verify the saved
  face remains. Repeat and save. With live T3, check the result on a fresh
  connection. In Demo, limit the claim to the current session.
- `avatars.identity` — Pair iOS to the disposable Mac workspace and verify
  both show the saved shape family and color. Open a cached face with an
  existing custom recipe and verify viewing does not rewrite it.
- `avatars.motion` — Observe a resting Space, a working Space, a request
  awaiting input, and a completed turn. Verify the face and cue remain
  appropriate when changing Spaces. Repeat with Reduce Motion.
- `avatars.containment` — Check the face inside the profile editor and
  conversation header at compact width and large Dynamic Type. Change Spaces
  during work and verify its cue follows the active Space.
